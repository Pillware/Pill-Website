Descriptions

Copy these as they are, or shorten them to fit.

One line

Pill is a modern, free and blazingly fast game engine written in Rust.

Short about 60 words

Pill is a free, open-source game engine written in Rust. It is built around a high-performance hybrid Entity Component System, reloads game code in about a second and produces tiny builds: a WebAssembly build fits in under 0.5 MB. Pill runs on Windows, Linux, macOS and the web, and is released under the MIT license.

Long about 170 words

Pill is a modern, free and blazingly fast game engine. Its core is written in Rust and built around a high-performance, archetype-based Entity Component System that can simulate hundreds of thousands of objects. The ECS is hybrid: developers can write data-oriented code, put logic straight into components in a classic object-oriented style, or mix both.

Fast iteration is central to Pill. Game code hot-reloads in about one to two seconds, and builds stay tiny, with a WebAssembly build under 0.5 MB. The engine is designed around a deliberately small core, with the goal that rendering, physics, audio and tooling become modules projects add only when they need them. Every engine update is checked by automated benchmarks, so performance claims are backed by real numbers.

Pill runs on Windows, Linux, macOS and the web. It is open source under the MIT license and community driven: the roadmap is voted on by its users. Pill is currently in development, with version 1.0 planned for the first quarter of 2027.

Features

Please keep these two lists apart: the first ships today, the second is where Pill is heading.

Available today

  • Archetype-based ECS
  • 3D graphics - Blinn-Phong, instancing
  • Material system and custom shaders
  • Scenes
  • Input - keyboard, mouse, gamepad
  • Sound - mono and spatial
  • Game project and engine code hot-reloading
  • Launcher tool
  • Error chaining
  • Windows, Linux, macOS and Web (wasm32)

Goals for Pill

  • C# and Rust as first-class scripting languages
  • Crash-resistant editor with full project sandboxing
  • Live game and scene editing side by side
  • Modular core - even run fully headless
  • Builds around 1 MB
  • Efficient streaming of huge worlds
  • Editor opening in seconds, even for large projects
  • Embedded devices such as ESP32-class microcontrollers
  • Readable JSON asset format

Writing about Pill

Good to know

Write the name as Pill, or Pill Engine where "Pill" alone could be unclear. Not "PILL" or "PillEngine".

Pill is still in development, so features and numbers can change before 1.0. Please mention that it is in development when you show it.

Linking to pillengine.org helps readers find the project.
