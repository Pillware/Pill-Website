# Brand identity

Pill's identity is a capsule and a lowercase name: simple, a little playful and
always calm on a dark background. This page explains how to use it and links
every logo file you need.

## Logo

The logo is the capsule followed by the wordmark. Use the supplied files as they
are; they are the only correct versions.

the circle, so the same file works for square app icons and for the circular crops

## Clear space and minimum size

Keep a space of **half the capsule's height** clear on every side of the logo.
Nothing goes there: no text, no other logos, no edge of the page or screen.

The capsule repeats as a quiet background pattern: one small capsule per cell, at
3 to 8% opacity on the dark surface. It sits behind content, never in front of it.
In chat and commit messages, Pill is 💊.
